
Przedmioty modyfikują statystyki bohatera takie jak prędkość, atak czy obrona. Przedmiot może być wielokrotnego użytku Miecz, jak i jednorazowy: mikstura.

Przedmiot może mieć speciajny effekt użycia, na przykład leczenie. Będzie działać to podobnie do systemu effetków ulepszeń.

Przedmioty mają poziomy:
-> 0, 1, 2, 3, Artefakt

Przykładowe przedmioty:
- Miecz lv 2
- Miecz ognia (po ataku podpala wroga) -> artefakt
- Zbroja lv 0
- Mikstura zdrowia
- Mikstura prędkości
- Amulet leczący
